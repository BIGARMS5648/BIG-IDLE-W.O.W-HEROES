# 스테이지 탭 그림 목록

스테이지 탭에 들어가는 그림은 두 종류, 모두 124장입니다.

- **세계 카드 4장**: 맨 위에 가로로 놓인 네 칸(모험의 시작 · 넓어지는 세계 · 깨어나는 위협 · 최후의 결전)의 뒷배경
- **스테이지 배너 120장**: 스테이지를 누르면 오른쪽 상세 칸 맨 위에 나오는 지역 그림

그림이 없는 칸은 지금처럼 테마 색을 입힌 기본 풍경이 나오므로, 다 만들지 않아도 되고 만든 것부터 넣을 수 있습니다.

## 1. 공통 규칙

| 항목 | 내용 |
| --- | --- |
| 크기 | **1024 × 256** (권장) 또는 512 × 128. 가로:세로 = 4:1. 두 변 모두 2의 거듭제곱이어야 합니다 |
| 형식 | **TGA**, 24비트(RGB) 또는 32비트(RGBA), **RLE 압축 끔** |
| 넣는 곳 | `BigWowIdle/Media/Stages/` 폴더 (없으면 새로 만듭니다) |
| 파일 이름 | 아래 표의 이름 그대로, 소문자 (예: `w1.tga`, `s1_01.tga`, `s4_30.tga`) |
| 넣지 말 것 | 글자, 로고, 지역 이름, 테두리 (게임이 이름·레벨·테두리를 따로 그립니다) |

**그림 분위기(권장):** 오리지널 와우 느낌의 가로로 긴 풍경 일러스트. 모든 그림을 같은 화풍·같은 밝기로 맞추면 탭이 깔끔해 보입니다. 우두머리나 몬스터는 넣지 않아도 되고, 넣는다면 작게 실루엣으로만 두는 것이 글자와 겹치지 않아 좋습니다.

### 세계 카드 (w1 ~ w4) — 화면에 보이는 모습

- 화면에서는 약 **218 × 60** 크기로 보입니다. 그림이 조금 더 납작하게 쓰이므로 **왼쪽·오른쪽 끝이 약 5%씩 잘립니다.**
- 카드 **왼쪽 약 2/3**에 왼쪽에서 오른쪽으로 옅어지는 검은 그림자가 깔리고, 그 위에 글자가 있습니다:
  - 왼쪽 위: 난이도 표(일반·영웅·신화·신화+)
  - 왼쪽 가운데: 세계 이름 (예: 모험의 시작)
  - 왼쪽 아래: 진행 (예: 진행 12 / 30)
  - 오른쪽 가운데: 잠긴 세계에는 자물쇠
- 잠긴 세계는 그림이 **흑백**으로 보입니다.
- 👉 **눈에 띄는 대상(성, 산, 용 등)은 오른쪽 절반에** 두고, 왼쪽은 하늘·땅처럼 단순하게 두세요.

### 스테이지 배너 (s1_01 ~ s4_30) — 화면에 보이는 모습

- 화면에서는 약 **384 × 76** 크기로 보입니다. 그림이 조금 더 납작하게 쓰이므로 **위·아래 끝이 약 10%씩 잘립니다.**
- 배너 **아래쪽 절반**에 아래에서 위로 옅어지는 검은 그림자가 깔리고, 왼쪽 아래에 글자 두 줄이 있습니다:
  - 위 줄(큰 글자): 지역 · 스테이지 이름 (예: 줄구룹 · 뱀의 신전)
  - 아래 줄(작은 글자): 난이도 · 레벨 · 웨이브 수
- 👉 **중요한 것은 위쪽 절반과 오른쪽에** 두세요. 왼쪽 아래는 글자 자리입니다.

### 같은 그림을 여러 스테이지에 쓰기

같은 던전·공격대 안의 스테이지(예: 줄구룹 10개, 화산 심장부 10개)는 따로 그려도 되고 한 장을 같이 써도 됩니다. 한 장을 같이 쓰려면 어느 스테이지에 어느 그림을 쓸지 알려 주세요 (예: "s3_11 ~ s3_20은 모두 s3_11"). 설정은 `BigWowIdle/Data/StageArt.lua`의 `ns.ART_READY` 목록에 있습니다.

### 그림을 넣은 뒤

그림 파일을 `Media/Stages/`에 넣은 다음 어떤 파일을 넣었는지 알려 주시면 목록(`ns.ART_READY`)에 올려 바로 보이게 해 드립니다. 직접 하려면 `Data/StageArt.lua`의 목록에 `s1_01 = true,`처럼 한 줄씩 넣으면 됩니다(목록에 없는 그림은 쓰이지 않으므로, 파일이 없는데 목록에 올리면 그 칸이 비어 보입니다). 그림을 바꾼 뒤에는 게임을 완전히 껐다 켜야 새 그림이 보입니다(/reload로는 새 파일을 읽지 않습니다).
