# Big Idle W.O.W Heroes

월드 오브 워크래프트: 포에버(WoW Forever)용 애드온입니다. 화면 한켠의 **전투 창**에서 영웅 파티가 저절로 싸우고, 플레이어는 틈틈이 장비·특성·룬을 관리하는 **방치형 파티 RPG 미니게임**입니다.

- 파티는 최대 **5명 (탱커 1 · 딜러 3 · 힐러 1)**
- 처음에 **얼라이언스 / 호드**를 고르면, 영웅이 진영별로 직업마다 정해진 **종족**의 모습이 됩니다
- **10개 직업, 31개 전문화** 중에서 골라 영웅을 만들고(새 직업 **땜장이**: 전투기계 탱커 · 포탑 딜러 · 치유 드론 힐러), **남/여**를 고르며, 종족과 성별에 맞는 **"이름 성" 형식의 무작위 이름**이 붙습니다 (최대 12명 보유)
- **특성**(능력치, 레벨마다 1점)과 **기술**(4레벨마다 1점, 레벨에 따라 열림)이 따로입니다
- 난이도마다 다른 세계: 일반 **아제로스** · 영웅 **아웃랜드** · 신화 **노스렌드** · 신화+ **부서진 세계** — 120개 지역이 모두 다릅니다
- 모바일 MMORPG 스타일 화면: 하단 메뉴 6개, 카드형 화면, 빨간 점 알림, "다음 목표" 안내, 보스 체력바
- 전투 창은 **오른쪽 아래 모서리를 끌어 크기 조절**(비율 유지)
- 캐릭터 **애니메이션**(대기·걷기·공격·기술·피격·사망), 움직이는 배경, 스킬 이펙트, 소환수·포탑, 드루이드 변신, 인터페이스 그림을 넣을 수 있는 구조. 그림은 `docs/ASSET_PROMPTS.md`의 프롬프트로 만들어 넣습니다(아래 "그림 넣기")
- 8등급 장비, 상자, 티탄 용광로(8가지 기능), 룬 트리, 동료, 오프라인 보상
- 한국어 전용 (영어 등 다른 언어 클라이언트에서도 한글 글꼴로 표시)

## 설치

1. 이 저장소의 `BigIdleWoWHeroes` 폴더를 통째로 와우 포에버의 `Interface/AddOns/` 아래에 복사합니다.
   (결과: `Interface/AddOns/BigIdleWoWHeroes/BigIdleWoWHeroes.toc`, 그 옆에 `Media/` 폴더)
2. 게임을 실행하고 캐릭터 선택 화면의 **애드온** 목록에서 `Big Idle W.O.W Heroes`를 켭니다.
3. 접속하면 **진영 선택** 창이 열립니다. 얼라이언스나 호드를 고르면 **영웅 만들기** 창이 이어서 열립니다. 직업 → 전문화 → 성별 → 이름을 정하면 첫 영웅이 무료로 만들어지고 전투가 시작됩니다.
4. 메뉴는 `/biwh` 또는 `/방치영웅`으로 열고 닫습니다 (`/biwh bar` 전투 창 표시/숨김, `/biwh reset` 전투 창 위치 초기화).

`BigIdleWoWHeroes.toc`의 `## Interface:` 값은 포에버 베타 기준인 **16001**입니다. "구버전 애드온"으로 표시되면 애드온 목록에서 *구버전 애드온 사용*을 켜거나, 게임에서 `/dump select(4, GetBuildInfo())`로 확인한 숫자로 바꾸면 됩니다.

예전 버전의 저장 데이터는 자동으로 옮겨집니다.
- 1.x: 직업별 영웅은 같은 역할의 전문화 영웅이 되고(레벨·장비·진행도 유지), 특성 점수는 돌려받습니다.
- 2.0: 특성 트리에 있던 기술은 새 기술 점수로 옮겨지고(새 한도를 넘는 단계만 돌려받음), 영웅마다 성별과 성(姓)이 붙습니다. 처음 접속할 때 진영을 고릅니다.

## 화면 구성

**전투 창 (HUD)** — 지역마다 색이 다른 배경 위에서 파티가 싸웁니다. 왼쪽 드래그로 옮기고, 오른쪽 아래 모서리로 크기를 바꾸고(우클릭하면 원래 크기), 우클릭으로 메뉴를 엽니다.
- 위: 난이도·지역 이름, 웨이브 진행 점(마지막은 해골 = 우두머리), 골드, 우두머리가 나오면 큰 체력바
- 아래: **다음 목표**(누르면 바로 하거나 해당 화면을 엽니다), 자동 진행 버튼, 상자 3종, 메뉴 바로가기(빨간 점 = 할 수 있는 일이 있음)

**메뉴 창** — 아래쪽 탭 6개로 이동하고, 설정은 위쪽 톱니바퀴 버튼에 있습니다. 알림 메시지는 메뉴 창 아래쪽(메뉴 창이 닫혀 있으면 전투 창 위)에 나타납니다.

| 탭 | 내용 |
| --- | --- |
| 편성 | 전투 순서대로 놓인 5자리 카드(왼쪽 힐러 … 오른쪽 탱커), 역할별 인원, 자동 편성, 보유 영웅(역할 필터, 출전/휴식/교체: 누구와), 영웅 만들기, 동료 창 |
| 영웅 | 왼쪽: 영웅과 그 둘레의 장비 10칸. 오른쪽: 장비(주요 능력치, 고른 칸의 장착 장비와 가방 속 후보를 좋은 순으로) / 기술(기술 점수, 장착 칸 3개, 기술 6개와 열리는 레벨, 지금·다음 수치) / 특성(특성 점수, 8단계 능력치 트리) |
| 가방 | 필터(무기/방어구/액세서리), 은행, 재료. 아이템을 누르면 오른쪽 카드에서 장착·분해·보호·보관. Alt+클릭 = 보호, 우클릭 = 분해. 일괄 분해는 두 번 눌러 실행하고 보호·보석·파티 업그레이드 장비는 남깁니다 |
| 용광로 | 왼쪽 목록에서 기능 선택: 융합 · 분해 · 제작 · 보석 세공 · 추출 · 마법부여 · 보너스 굴림 · 룬 각인. 홈 작업은 오른쪽 위 초상화로 영웅을 고릅니다 |
| 룬 | 6갈래 룬 트리. 누르면 오른쪽 카드에서 배우기, 먼저 필요한 룬과 총비용, 배운 룬 보너스 합계 |
| 지도 | 4개 세계 → 3막 → 10개 지역. 지역 카드에 우두머리 기술·몬스터·보상 |
| 설정 (톱니바퀴) | 메뉴 창·전투 창 크기, 전투 창 작게 보기·잠금, 진영 바꾸기, 통계, 도움말, 초기화 |

## 밸런스

`tests/`의 도구로 맞췄습니다.

- **전문화 밸런스** (`python3 tests/run.py bench`): 같은 동료·레벨·장비로 각 전문화를 넣어 비교합니다. 딜러는 죽지 않는 목표(단일 대상 + 3마리 무리)에 대한 파티 총 피해로, 탱커·힐러는 실제 피해를 받는 어려운 스테이지에서 측정하고, 전문화별 보정값(`Data/Classes.lua`의 `ns.SPEC_TUNE`)을 조정합니다. 결과: 땜장이를 포함해 같은 역할 안에서 모든 전문화가 중앙값의 약 ±2% 안에 있습니다(보정 전 최대 10% 차이).
- **진행 속도** (`python3 tests/run.py balance 330`): 봇이 쉬지 않고 최적에 가깝게 관리할 때 일반 완료 약 8.6시간, 영웅 약 52시간, 신화 약 136시간, 330시간 시점에 신화+ 26/30 지역(특성·기술 분리 전과 비교해 4% 안쪽 차이). 각 막의 공격대 우두머리가 넘기 어려운 벽 역할을 하되 며칠씩 막히지 않도록 조정했습니다.

## 그림 넣기 (애니메이션, 배경, 이펙트, 인터페이스)

애드온은 그림이 없어도 지금 모습(아이콘·원형 초상화)으로 동작하고, 그림이 들어온 것부터 자동으로 바뀝니다.

1. `docs/ASSET_PROMPTS.md`의 프롬프트로 이미지 생성 AI(챗지피티 등)에서 그림을 만듭니다. 236장, 우선순위 3단계(1단계 113장: 그림체 기준, 인터페이스, 아이콘, 영웅 40명, 배경 6종).
2. 문서에 적힌 파일 이름 그대로 PNG를 저장해 저장소의 `art_src/` 폴더에 넣습니다.
3. `python3 tools/import_art.py`가 배경을 지우고, 프레임을 찾아 크기·발 위치를 맞추고, 게임용 TGA(`BigIdleWoWHeroes/Media/Art/`)와 목록(`Data/Art.lua`)을 만듭니다. `--check`는 빠진 파일을 알려 줍니다.

목록은 `tools/asset_spec.py` 한 곳에서 정의되고, 프롬프트 문서는 `python3 tools/make_prompts.py`로 다시 만들 수 있습니다.

## 설계에 대해

*Task Bar Hero* 류의 "작업 표시줄 방치형 RPG"가 가진 **시스템 구성**(자동 전투, 특성 트리, 등급별 홈이 있는 장비, 9개 융합, 큐브형 제작대, 룬 트리, 동료, 오프라인 보상)을 참고해 같은 장르로 만들었습니다. 이름·지역·몬스터는 워크래프트 테마이고, 아이템/기술/룬 목록, 확률표, 수치는 이 애드온용으로 새로 설계했습니다.

**그림:** `BigIdleWoWHeroes/Media/`의 UI 이미지(패널, 버튼, 슬롯, 링, 역할 아이콘, 지역 배경 등 30종)는 모두 `tools/make_art.py`가 직접 그려 만든 것입니다. 아이템·기술·직업 아이콘은 게임 클라이언트에 이미 들어 있는 아이콘 경로만 참조합니다(파일을 포함하지 않음).

Task Bar Hero 및 그 개발사, Blizzard Entertainment와는 아무 관련이 없는 팬 제작물입니다.

**주의:** 위 검증은 모두 모의 API에서 한 것이며, 이 코드는 실제 와우 포에버 클라이언트에서 실행해 본 적이 없습니다. 실제 클라이언트에서 Lua 오류가 나면 오류 메시지(`/console scriptErrors 1`)와 함께 알려 주세요. 아이콘이 클라이언트에 없으면 그 칸만 비어 보일 수 있습니다.

## 폴더 구조

```
BigIdleWoWHeroes/        애드온 본체 (이 폴더를 AddOns에 복사)
  Core/                  공용 유틸리티, 글꼴, 이벤트
  Data/                  직업·전문화, 진영·종족, 기술, 이름, 몬스터, 지역, 아이템, 룬, 동료, 그림 목록(Art.lua)
  Systems/               저장, 능력치, 아이템, 영웅, 상자, 용광로, 전투, 오프라인, 목표 안내
  UI/                    위젯, 스프라이트(애니메이션), 전투 창, 메뉴 창과 각 화면
  Media/                 기본 UI 이미지 (TGA), Art/ = 가져온 그림
art_src/                 직접 만든 그림 원본 (PNG, 게임에는 들어가지 않음)
docs/ASSET_PROMPTS.md    그림 프롬프트 목록
tests/                   모의 WoW API, 봇, 테스트, 벤치마크, 미리보기
tools/make_art.py        기본 UI 이미지 생성기
tools/asset_spec.py      그림 목록 (프롬프트·가져오기 공용)
tools/make_prompts.py    프롬프트 문서 생성기
tools/import_art.py      그림 가져오기 도구
```

진행 상황은 계정 공용 SavedVariables(`BigIdleWoWHeroesDB`)에 저장됩니다.
