# Big Idle W.O.W Heroes

월드 오브 워크래프트: 포에버(WoW Forever)용 애드온입니다. 화면 한켠의 작은 **전투 바**에서 영웅 파티가 저절로 싸우고, 플레이어는 틈틈이 장비·기술·룬을 관리하는 **방치형 파티 RPG 미니게임**입니다.

- 파티는 최대 **5명 (탱커 1 · 딜러 3 · 힐러 1)**
- 3막 × 10스테이지 × 4난이도(일반/영웅/신화/신화+) = 120개 스테이지
- 9개 직업, 직업마다 8단계 특성 트리와 6개 액티브 기술
- 8등급 장비, 상자, 티탄 용광로(8가지 제작 기능), 룬 트리, 동료, 오프라인 보상
- 한국어 / 영어 지원 (클라이언트 언어 자동 감지)

> An idle party auto-battler that plays itself in a slim bar inside World of Warcraft: Forever. Up to five heroes (1 tank, 3 damage, 1 healer), 120 stages, gear, a forge, a rune tree and offline rewards. Korean and English.

## 설치

1. 이 저장소의 `BigIdleWoWHeroes` 폴더를 통째로 와우 포에버의 `Interface/AddOns/` 아래에 복사합니다.
   (결과: `Interface/AddOns/BigIdleWoWHeroes/BigIdleWoWHeroes.toc`)
2. 게임을 실행하고 캐릭터 선택 화면의 **애드온** 목록에서 `Big Idle W.O.W Heroes`를 켭니다.
3. 접속하면 메뉴가 열립니다. **파티** 탭에서 첫 영웅을 무료로 영입하면 전투가 시작됩니다.

`BigIdleWoWHeroes.toc`의 `## Interface:` 값은 포에버 베타 기준인 **16001**입니다. 클라이언트 버전이 올라가 "구버전 애드온"으로 표시되면 애드온 목록에서 *구버전 애드온 사용*을 켜거나, 게임에서 `/dump select(4, GetBuildInfo())`로 확인한 숫자로 이 값을 바꾸면 됩니다.

| 명령 / 동작 | 설명 |

애드온 목록 버튼(애드온 칸)에서도 메뉴를 열 수 있습니다.

## 시스템 요약

| 시스템 | 내용 |
| --- | --- |
| 전투 | 영웅은 자동으로 싸웁니다. 스테이지는 10웨이브(공격대는 4웨이브)이고 마지막 웨이브에 우두머리가 나옵니다. 전멸하면 이전 스테이지로 물러났다가 8번 깬 뒤 자동으로 재도전합니다. |
| 파티 | 1번 자리 탱커, 2~4번 딜러, 5번 힐러. 처음에는 1명이며 **지휘의 룬** 4개로 5명까지 늘립니다. |
| 직업 | 전사·드루이드(탱커) / 사냥꾼·마법사·도적·흑마법사·주술사(딜러) / 사제·성기사(힐러) |
| 능력치 | `최종값 = (기본 + 고정 합) × (1 + 추가% 합) × 곱연산`. 피해 경감 순서: 회피 → 방어(절반) → 저항/방어도 → 받는 피해 감소 → 피해 흡수 → 보호막 |
| 기술 | 발동 방식 3종: 기본 공격 N회마다 / 재사용 대기시간 / 지속 효과(오라). 레벨 1~5는 기술 점수, 6~10은 "모든 기술 레벨" 장비로만 |
| 장비 | 부위 10곳, 8등급(하급~신화). 등급이 높을수록 고유 옵션과 보석·마법부여·각인 홈이 늘어납니다. |
| 상자 | 낡은 상자(몬스터) / 우두머리의 궤짝 / 공격대 보물 상자. 보관 한도가 있으며 **개봉의 룬**으로 자동 개봉 |
| 티탄 용광로 | 융합(9개→상위 1개) · 용해(골드) · 제작 · 보석 세공 · 마법부여 · 룬 각인 · 추출 · 보너스 굴림. 아이템을 소모할수록 용광로 레벨이 오릅니다. |
| 룬 | 골드로 배우는 계정 전체 강화. 전쟁/수호/재물/성장/탐험/지휘 6갈래 |
| 동료 | 특정 유형의 적을 일정 수 처치하면 획득. 효과는 항상 적용 |
| 오프라인 보상 | 접속하지 않은 시간만큼 골드·경험치 지급(기본 8시간 한도, 30일 이상은 0) |

## 설계에 대해 (참고한 게임과의 관계)

이 애드온은 *Task Bar Hero* 류의 "작업 표시줄 방치형 RPG"가 가진 **시스템 구성**(자동 전투, 직업별 특성 트리, 등급별 홈이 있는 장비, 9개 융합, 큐브형 제작대, 룬 트리, 동료, 오프라인 보상 등)을 참고해 같은 장르의 메커니즘으로 만들었습니다. 다만 다음은 그대로 가져오지 않고 새로 만들었습니다.

- 이름·캐릭터·그래픽·사운드: 전부 워크래프트 테마이며, 그림은 **게임 클라이언트에 이미 들어 있는 아이콘 경로만 참조**합니다(별도 이미지 파일 없음).
- 스테이지 구성, 아이템/기술/룬 목록, 확률표, 수치 밸런스: 이 애드온용으로 새로 설계하고 시뮬레이션으로 조정했습니다.
- 파티 규모: 원작의 3인이 아니라 요청대로 **탱커 1 · 딜러 3 · 힐러 1의 5인**입니다.
- 스팀 장터 거래, 캐릭터 꾸미기(스킨)처럼 애드온에서 의미가 없는 기능은 넣지 않았습니다.

Task Bar Hero 및 그 개발사, Blizzard Entertainment와는 아무 관련이 없는 팬 제작물입니다.

## 테스트

게임 클라이언트 없이도 로직과 UI 코드를 검증할 수 있도록, WoW UI API를 흉내 낸 모의 환경과 자동 플레이 봇이 `tests/`에 들어 있습니다.

```bash
pip install lupa
```

```bash
python3 tests/run.py
```

- `systems`: 데이터 무결성, 파티 역할 규칙, 능력치 계산, 아이템, 상자, 용광로, 전투, 오프라인 보상
- `ui`: 실제 로딩 순서대로 애드온을 띄운 뒤 모든 탭을 열고, 툴팁을 띄우고, 버튼을 수천 번 무작위로 누릅니다(한국어/영어).
- `balance N`: 봇이 N시간 분량을 플레이하며 진행 속도를 출력합니다.
- `cover`: 테스트가 실행한 코드 줄 비율을 파일별로 보여 줍니다.

**주의:** 위 테스트는 모의 API에서 돌린 것이며, 이 저장소의 코드는 실제 와우 포에버 클라이언트에서 실행해 본 적이 없습니다. 실제 클라이언트에서 Lua 오류가 나면 오류 메시지(`/console scriptErrors 1`)와 함께 알려 주세요.

## 폴더 구조

```
BigIdleWoWHeroes/        애드온 본체 (이 폴더를 AddOns에 복사)
  Core/                  공용 유틸리티, 언어 처리
  Data/                  직업, 기술, 몬스터, 스테이지, 아이템, 룬, 동료 데이터
  Systems/               저장, 능력치, 아이템, 영웅, 상자, 용광로, 전투, 오프라인
  UI/                    전투 바, 메인 창과 탭
tests/                   모의 WoW API, 자동 플레이 봇, 테스트 스크립트
```

진행 상황은 계정 공용 SavedVariables(`BigIdleWoWHeroesDB`)에 저장됩니다.
