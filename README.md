# Big Idle W.O.W Heroes

월드 오브 워크래프트: 포에버(WoW Forever)용 애드온입니다. 화면 한켠의 **전투 창**에서 영웅 파티가 저절로 싸우고, 플레이어는 틈틈이 장비·특성·룬을 관리하는 **방치형 파티 RPG 미니게임**입니다.

- 파티는 최대 **5명 (탱커 1 · 딜러 3 · 힐러 1)**
- **9개 직업, 28개 전문화** 중에서 골라 영웅을 만들고, 영웅마다 **무작위 이름**이 붙습니다 (최대 12명 보유)
- 난이도마다 다른 세계: 일반 **아제로스** · 영웅 **아웃랜드** · 신화 **노스렌드** · 신화+ **부서진 세계** — 120개 지역이 모두 다릅니다
- 모바일 MMORPG 스타일 화면: 하단 메뉴, 카드형 화면, 빨간 점 알림, "다음 목표" 안내, 보스 체력바
- 8등급 장비, 상자, 티탄 용광로(8가지 기능), 룬 트리, 동료, 오프라인 보상
- 한국어 / 영어 (클라이언트 언어 자동 감지)

> An idle party auto-battler for World of Warcraft: Forever. Create heroes from 28 specializations (random names), field up to five (1 tank, 3 damage, 1 healer), and push through four worlds of 30 zones each. Mobile-RPG style interface. Korean and English.

## 설치

1. 이 저장소의 `BigIdleWoWHeroes` 폴더를 통째로 와우 포에버의 `Interface/AddOns/` 아래에 복사합니다.
   (결과: `Interface/AddOns/BigIdleWoWHeroes/BigIdleWoWHeroes.toc`, 그 옆에 `Media/` 폴더)
2. 게임을 실행하고 캐릭터 선택 화면의 **애드온** 목록에서 `Big Idle W.O.W Heroes`를 켭니다.
3. 접속하면 **영웅 만들기** 창이 열립니다. 직업 → 전문화를 고르면 첫 영웅이 무료로 만들어지고 전투가 시작됩니다.

`BigIdleWoWHeroes.toc`의 `## Interface:` 값은 포에버 베타 기준인 **16001**입니다. "구버전 애드온"으로 표시되면 애드온 목록에서 *구버전 애드온 사용*을 켜거나, 게임에서 `/dump select(4, GetBuildInfo())`로 확인한 숫자로 바꾸면 됩니다.

1.x에서 쓰던 저장 데이터는 자동으로 옮겨집니다. 직업별 영웅은 같은 역할의 전문화 영웅이 되고(레벨·장비·진행도 유지), 특성 트리가 바뀌었기 때문에 특성 점수는 돌려받습니다.

## 화면 구성

**전투 창 (HUD)** — 지역마다 색이 다른 배경 위에서 파티가 싸웁니다.
- 위: 난이도·지역 이름, 웨이브 진행 점(마지막은 해골 = 우두머리), 골드, 우두머리가 나오면 큰 체력바
- 아래: **다음 목표**(누르면 바로 하거나 해당 화면을 엽니다), 자동 진행 버튼, 상자 3종, 메뉴 바로가기(빨간 점 = 확인할 것 있음)

**메뉴 창** — 아래쪽 탭으로 이동합니다.

| 탭 | 내용 |
| --- | --- |
| 편성 | 역할별 5자리 카드, 보유 영웅 목록(출전/휴식/교체 출전), 영웅 만들기, 동료 |
| 영웅 | 영웅 줄에서 선택 → 장비(장비 칸 + 능력치, 일괄 장착) / 특성(8단계 트리, 자동 배분) / 기술(장착 슬롯 3개 + 기술 카드) |
| 가방 | 필터(무기/방어구/장신구), 은행, 재료. 아이템을 누르면 오른쪽 카드에서 장착·분해·잠금·보관 |
| 용광로 | 융합 · 분해 · 제작 · 보석 세공 · 추출 · 마법부여 · 보너스 굴림 · 룬 각인 |
| 룬 | 6갈래 룬 트리. 누르면 오른쪽 카드에서 배우기, 보너스 합계 |
| 지도 | 4개 세계 → 3막 → 10개 지역. 지역 카드에 우두머리 기술·몬스터·보상 |
| 설정 | 크기, 전투 창 작게 보기, 언어, 통계, 초기화 |

## 밸런스

`tests/`의 도구로 맞췄습니다.

- **전문화 밸런스** (`python3 tests/run.py bench`): 같은 동료·레벨·장비로 각 전문화를 넣어 비교합니다. 딜러는 죽지 않는 목표(단일 대상 + 3마리 무리)에 대한 파티 총 피해로, 탱커·힐러는 실제 피해를 받는 어려운 스테이지에서 측정하고, 전문화별 보정값(`Data/Classes.lua`의 `ns.SPEC_TUNE`)을 조정합니다. 결과: 같은 역할 안에서 모든 전문화가 중앙값의 약 ±2.5% 안에 있습니다(보정 전 최대 10% 차이).
- **진행 속도** (`python3 tests/run.py balance 330`): 봇이 쉬지 않고 최적에 가깝게 관리할 때 일반 완료 약 8시간, 영웅 약 48시간, 신화 약 120시간, 신화+ 마지막 지역은 330시간 이상. 각 막의 공격대 우두머리가 넘기 어려운 벽 역할을 하되 며칠씩 막히지 않도록 조정했습니다.

## 설계에 대해

*Task Bar Hero* 류의 "작업 표시줄 방치형 RPG"가 가진 **시스템 구성**(자동 전투, 특성 트리, 등급별 홈이 있는 장비, 9개 융합, 큐브형 제작대, 룬 트리, 동료, 오프라인 보상)을 참고해 같은 장르로 만들었습니다. 이름·지역·몬스터는 워크래프트 테마이고, 아이템/기술/룬 목록, 확률표, 수치는 이 애드온용으로 새로 설계했습니다.

**그림:** `BigIdleWoWHeroes/Media/`의 UI 이미지(패널, 버튼, 슬롯, 링, 역할 아이콘, 지역 배경 등 30종)는 모두 `tools/make_art.py`가 직접 그려 만든 것입니다. 아이템·기술·직업 아이콘은 게임 클라이언트에 이미 들어 있는 아이콘 경로만 참조합니다(파일을 포함하지 않음).

Task Bar Hero 및 그 개발사, Blizzard Entertainment와는 아무 관련이 없는 팬 제작물입니다.

## 테스트와 도구

게임 없이 로직과 화면을 검증할 수 있도록 WoW UI API를 흉내 낸 모의 환경과 자동 플레이 봇이 있습니다.

```bash
pip install lupa pillow numpy
```

```bash
python3 tests/run.py
```

| 명령 | 하는 일 |
| --- | --- |
| `python3 tests/run.py systems` | 데이터 무결성(전문화, 120개 지역, 기술), 파티 역할, 영웅 생성·이름, 능력치, 아이템, 용광로, 전투, 저장 데이터 이전 |
| `python3 tests/run.py ui` | 실제 로딩 순서대로 띄운 뒤 모든 화면의 흐름(영웅 만들기, 출전 교체, 특성, 기술, 가방, 용광로, 룬, 지도, 전투 창)을 눌러 보고, 버튼을 수천 번 무작위로 누릅니다 (한국어/영어) |
| `python3 tests/run.py balance 330` | 봇이 330시간 분량을 플레이하며 진행 속도를 출력 |
| `python3 tests/run.py bench` | 전문화 밸런스 측정·조정 |
| `python3 tests/run.py cover` | 테스트가 실행한 코드 줄 비율 |
| `python3 tools/make_art.py` | UI 이미지 다시 만들기 |
| `python3 tests/preview.py koKR` | 화면 배치 미리보기 `tests/out/preview_koKR.html` (실제 UI 이미지 사용, 게임 아이콘은 대체 그림) |

**주의:** 위 검증은 모두 모의 API에서 한 것이며, 이 코드는 실제 와우 포에버 클라이언트에서 실행해 본 적이 없습니다. 실제 클라이언트에서 Lua 오류가 나면 오류 메시지(`/console scriptErrors 1`)와 함께 알려 주세요. 아이콘이 클라이언트에 없으면 그 칸만 비어 보일 수 있습니다.

## 폴더 구조

```
BigIdleWoWHeroes/        애드온 본체 (이 폴더를 AddOns에 복사)
  Core/                  공용 유틸리티, 언어 처리
  Data/                  직업·전문화, 기술, 이름, 몬스터, 지역, 아이템, 룬, 동료
  Systems/               저장, 능력치, 아이템, 영웅, 상자, 용광로, 전투, 오프라인, 목표 안내
  UI/                    위젯, 전투 창, 메뉴 창과 각 화면
  Media/                 UI 이미지 (TGA)
tests/                   모의 WoW API, 봇, 테스트, 벤치마크, 미리보기
tools/make_art.py        UI 이미지 생성기
```

진행 상황은 계정 공용 SavedVariables(`BigIdleWoWHeroesDB`)에 저장됩니다.
